# Sound credits

The game's recorded sounds (`src/audio/assets/`) are cut from these field
recordings, found on [Freesound](https://freesound.org). This file is
generated by `npm run audio:build` from `scripts/audio/sources.json`.

- [airliner_ascend.aif](https://freesound.org/s/51091/) by Heigh-hoo, CC0 1.0 (public domain dedication) ([license](https://creativecommons.org/publicdomain/zero/1.0/)). Cut, mixed to mono, levelled, looped and re-encoded: `engine-jet-idle.flac`, `engine-jet-full.flac`.
- [Airplane Flyby](https://freesound.org/s/431206/) by oscaraudiogeek, CC0 1.0 (public domain dedication) ([license](https://creativecommons.org/publicdomain/zero/1.0/)). Cut, mixed to mono, levelled and re-encoded: `whoosh-3.mp3`.
